# telecom-measurements

Учебные материалы дисциплины **«Измерения в телекоммуникационных системах»** — лекции и лабораторные работы с моделями и скриптами в среде [Engee](https://engee.com/).

- **Специальность:** 10.05.02 «Информационная безопасность телекоммуникационных систем»
- **Специализация:** № 9 «Управление безопасностью телекоммуникационных систем и сетей»
- **Платформа лабораторного практикума:** Engee (ядро IJulia)

## Содержание репозитория

```
telecom-measurements/
├── lectures/   # лекции курса (готовятся к публикации)
├── lab/        # методические указания к ЛР (.ngscript — ноутбук Engee)
├── models/     # модели Engee (.engee) к каждой ЛР
└── scripts/    # Julia-скрипты (.jl) анализа результатов измерений
```

Файлы, относящиеся к одной лабораторной работе, объединены номером `LRNN` в имени: методичка в `lab/`, модель в `models/`, скрипт в `scripts/`.

## Как работать с материалами

1. Открыть методичку соответствующей ЛР из `lab/*.ngscript` — интерактивный ноутбук Engee с целью работы, теорией, порядком выполнения, индивидуальными вариантами и критериями оценки.
2. Открыть модель `models/LRNN_*.engee` на платформе Engee, выставить параметры своего варианта.
3. Выполнить скрипт `scripts/LRNN_*.jl`, получить и зафиксировать результаты измерений в отчёте.
